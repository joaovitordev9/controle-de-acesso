# Backlog de issues — Controle de Acesso

As issues foram separadas em arquivos por etapa para facilitar a execução. Cada arquivo contém descrição, dependências, labels e critérios de aceite.

## Etapas

1. [Fundação e segurança](01-fundacao-e-seguranca.md) — configuração segura e erros da API (issues 1–2).
2. [Cadastro e gestão de clientes](02-clientes-e-historico.md) — busca, formulário e preservação do histórico (issues 3–5).
3. [Entradas, saídas e pulseiras](03-entradas-e-pulseiras.md) — operação de acesso e consulta de pessoas dentro (issues 6–8).
4. [Convites e autorizações](04-convites-e-autorizacoes.md) — cotas, API, vínculo com entrada e telas (issues 9–13).
5. [Relatórios e exportação](05-relatorios-e-exportacao.md) — consulta, exportação e interface (issues 14–16).
6. [Qualidade e documentação](06-testes-e-documentacao.md) — testes críticos e guia de execução (issues 17–18).

## Ordem geral sugerida

1. Fundação e segurança.
2. Cadastro e gestão de clientes.
3. Entradas, saídas e pulseiras.
4. Convites e autorizações.
5. Relatórios e exportação.
6. Testes e documentação, avançando junto das funcionalidades.

A numeração original das issues foi preservada para facilitar referência cruzada.
